# GeoCourse 0.1 test files

[`manifest.json`](manifest.json) lists every file with its expected result. A validator must accept each valid file and reject each invalid file with an error for the rule named. `message` is a substring of the reference validator's error, to help other validators match up.

- `valid/`: files a reader must accept and ride.
- `invalid/`: one file per rule of section 8, each breaking only that rule.

The files are generated by `npm run make-tests` (`scripts/make-tests.ts`); `example-ramp` is taken verbatim from section 9 of the spec. CI runs the reference validator and the schema against all of them with `npm test`.
